# Expense Tracker — Project Documentation

An offline-first personal expense tracker mobile app built with Expo and React Native.

## Product Goal

Make recording a daily expense extremely fast while giving clear weekly and monthly spending insights.

## Core Principles

- Offline-first
- Local-only data
- Fast expense entry
- Mobile-first UX
- Privacy by default
- Premium glassmorphism visual language
- Simple personal finance workflows
- No unnecessary backend complexity

- Expo Haptics

## Non-Goals

The first version will not include:

- Cloud synchronization
- User accounts
- Banking integrations
- Automatic bank transaction imports
- Multi-user functionality
- Investment tracking
- Complex accounting
