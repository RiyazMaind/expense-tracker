## Definition of Done

The MVP is complete when:

- Expenses can be added, edited, and deleted
- Data persists locally
- App works offline
- Dashboard totals are correct
- Weekly and monthly analytics are correct
- Budget works
- UI follows the glassmorphism design system
- Core flows pass E2E tests
- No major mobile layout issues remain
